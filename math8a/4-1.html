📄 解一元二次方程式速查表

🎩 意思一個未知數、最高次是 2 的等式，例如 \(x^2-5x+6=0\)（要先整理再判斷）
解（根）：代進去會成立的數
0️⃣ 乘起來是 0\(A\times B=0\Rightarrow A=0\) 或 \(B=0\)：\((x-3)(x+5)=0\Rightarrow x=3\) 或 \(-5\)
🧩 因式分解法① 移項讓右邊是 0 ② 因式分解 ③ 每個括號 ＝ 0
不可兩邊同除以 x（會漏掉 x＝0）；乘起來不是 0 不能拆
🔁 重根、開根號\((x+3)^2=0\Rightarrow x=-3\)（重根）；\((x+1)^2=16\Rightarrow x+1=\pm4\)
🔄 變化題右邊不是 0 先展開移項；兩邊同一包不能約（移項提出）
已知兩根 3、−5 → \((x-3)(x+5)=0\)；\(k\) 是根 → \(k^2+k=1\) 整包代入
