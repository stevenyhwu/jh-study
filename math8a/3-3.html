第 3 章 因式分解

3-3 利用十字交乘法作因式分解

找兩個數 ✖️老師課程：國二上 3-3
🐱
\(x^2+5x+6\) 要拼成長方形禮盒，祕訣是找兩個數：
乘起來是最後的數、加起來是中間的數！找到了，畫個十字就搞定。
每一關都可以直接點進去玩 👇

📄 十字交乘速查表

🔎 找兩個數\(x^2+bx+c=(x+m)(x+n)\)：\(m\times n=c\)、\(m+n=b\)
\(x^2+7x+12=(x+3)(x+4)\)
➕ 正負號最後是 ＋ → 同號，跟中間同號；最後是 － → 一正一負，大的跟中間同號
✖️ 十字左邊乘起來＝\(ax^2\)，右邊乘起來＝常數，交叉相乘加起來＝中間項；橫著讀每一列
\(2x^2+7x+3=(2x+1)(x+3)\)；湊不到就換位置、換拆法
🏆 提醒先提公因式：\(2x^2-10x+12=2(x-2)(x-3)\)；檢查因式：代進去等於 0
